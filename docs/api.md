>```

|---|---|---|
|project_id|Text|Project slug or ID (required)|
|task_id|Text|Task ID (optional, scopes file to task)|
|file|File|File upload (`.pdf`, `.txt`, `.md`, `.docx` allowed)|

Requires `accessToken` cookie. Rate limited to 6 requests/minute.
